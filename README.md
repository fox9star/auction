## 🌟 주요 핵심 기능

### 1. 🔲 4대 인터랙티브 뷰 모드
- **카드 뷰 (Card View)**: 사건별 핵심 권리분석, 유찰 히스토리 및 다음 회차 최저가 시뮬레이션, 할인율 태그 제공.
- **표 뷰 (Table View)**: 다량의 경매 물건을 엑셀처럼 한눈에 정렬 및 대량 비교.
- **전국 경매 지도 뷰 (Map View)**: 전국 법원별 경매 물건 위치를 Leaflet 기반 마커 클러스터링으로 시각화.
- **입찰 캘린더 뷰 (Calendar View)**: 월별/일자별 전국 경매 기일 달력 및 당일 매물 드로어 패널 연동.

### 2. ⚡ 원클릭 빠른 조건 필터 (Quick Filters)
- `✅ 위반없는 클린건물`: 건축물대장상 위반건축물 및 이행강제금 위험 없는 안심 매물 필터.
- `🌐 외국인 세입자`: 출입국관리소 체류확인서 열람이 필수적인 외국인 임차인 매물 필터.
- `👤 소유자 직접 거주`: 명도가 비교적 수월한 소유자 점유 매물.
- `⚠️ 선순위 대항력 주의`: 보증금 인수 위험이 있는 선순위 임차인 집중 점검.
- `⚖️ 전세금 반환 강제경매`: 전세보증금 미반환으로 경매 신청된 빌라/아파트 타깃.
- `📉 3회 이상 다회유찰`: 감정가 대비 65% 이상 파격 할인된 반값 경매 매물.

### 3. 🛠️ 7대 실전 투자자 전문 도구
1. **📝 대법원 공식 기일입찰표 & 매각기일 입찰봉투 자동 작성**
   - 대법원 규칙 양식 28호 정밀 서식 자동 렌더링.
   - 사건번호, 물건번호, 본인 인적사항, 입찰가격 및 보증금액 한글/숫자 자동 기재, A4 즉시 인쇄.
2. **🏦 경락잔금대출 한도 & 방공제(최우선변제금) & 실투자금 계산기**
   - 시도별 최우선변제금(소액임차보증금) 방공제 자동 산출 및 MCI/MCG 보증보험 면제 옵션.
   - 취득세(1주택~다주택, 법인), 국민주택채권, 법무사 비용, 명도비 포함 총 필요 자금 계산.
3. **🎯 AI 예상 낙찰가율 3대 시나리오 분석기**
   - 수익 극대화형(보수적, 낙찰 확률 ~32%), 적정 균형형(통계 추천, 낙찰 확률 ~70%), 확실한 낙찰형(공격적, 낙찰 확률 ~88%).
4. **📋 현장 임장 10대 체크리스트 & 체납관리비 분리 계산기**
   - 대법원 전원합의체 판례(2001다42010) 기준 공용부분 원금 승계 vs 전용부분/연체료 면책 분리 계산.
   - 관리사무소 제출용 공식 협상문 자동 생성.
5. **📜 점유자 명도 협상 안내문 & 법원 인도명령 신청서 양식 생성**
   - 민사집행법 제136조에 따른 부동산 인도명령 신청서 작성.
   - 부드러운 이사비 합의 통지문 원클릭 복사.
6. **🏛️ 실전 당일 모바일 법원 입찰장 동행 모드 (`Court Day Live`)**
   - 전국 법원별 입찰함 마감 카운트다운 타이머 (초 단위 실시간).
   - 3대 필수 지참물(신분증, 도장, 보증금 수표) 현장 체크리스트.
   - 사건번호/보증금/입찰가 한글 금융 표기 대형 돋보기 뷰.
7. **💰 3대 출구전략(단기매매 vs 전세갭 vs 월세연금) 세후 순이익 비교기**
   - 단기매매 양도소득세 공제 후 세후 순이익/ROI, 전세 갭투자 회수금 및 무피/플러스피(+P) 판정, 월세 순현금흐름 및 ROE 동시 산출.

### 4. 🤖 경매 AI 전문 상담 챗봇
- 내장된 법원경매 지식베이스(KB) 기반으로 서버 없이도 100% 오프라인 질의응답 지원.
- Google Gemini API 키 연동 시 최신 LLM 기반 심층 상담 지원.

## 💻 로컬 실행 방법

### 요구 사항
- Python 3.9 이상
- 최신 웹 브라우저 (Chrome, Edge 등)

### 1. 실시간 서버 구동
```bash
# Windows
실시간_연동_서버_실행.bat

# 또는 직접 파이썬 실행
python auction_live_server.py
```
- 브라우저에서 `http://127.0.0.1:8765/index.html` 로 접속합니다.

### 2. 포털 HTML 직접 재생성
```bash
python build_portal.py
```
